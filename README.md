# DSA Visualizer

An interactive and user-friendly **DSA Visualizer** designed to help students and beginners understand the working of various **Data Structures and Algorithms** through real-time animations and graphical visualization.

The project provides visual demonstrations for sorting algorithms, searching algorithms, graph traversal, and tree data structures, making learning DSA easier and more engaging.

---

## 🚀 Features

- 📊 Sorting Algorithm Visualization
- 🔍 Searching Algorithm Visualization
- 🌳 Tree Data Structure Visualization
- 📈 Graph Representation and Traversal
- 🎨 Interactive and Responsive UI
- ⚡ Real-Time Algorithm Animation
- 🧑‍💻 Beginner-Friendly Learning Interface

---
